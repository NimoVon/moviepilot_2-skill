# MoviePilot 站点管理

站点页 Web 路由：`http://<host>:3000/#/site`。卡片按优先级排序，右上角图标 = 连接状态。

> 提醒：若未通过用户认证（`AUTH_SITE`），私有/公开站点都无法维护与使用。
> MoviePilot 不再持续更新站点清单，以 设定 -> 关于 中最新支持为准。

## 站点卡片信息
- ↑ 上传量 / ↓ 下载量（两个进度条）
- 域名地址
- 连接状态图标：绿=正常且响应快；黄=可连通但平均 >5s（慢）；红=无法连接或超时

## 手动添加站点（站点管理右下角 +）
字段：
- **站点地址**：站点访问域名，需在支持站清单内。
- **优先级**：搜索排序，数值越小越优先（也可拖动卡片排序）。
- **RSS 地址**：点站点 RSS 按钮，选影视分类、条数设最大，复制 BT 客户端 RSS 链接填入。用于「站点RSS」订阅模式。
- **超时时间**：搜索时等站点返回的最大时间。连通好可设小（如 10），响应大设大（如 30）。设太大且站点连不上会拖慢搜索。
- **站点 Cookie**：浏览器开发者工具 -> 网络 -> 主页面请求 -> 请求头 Cookie 值。
- **请求头 Authorization**：个别站点不用 Cookie 用 Authorization（已知：馒头）。
- **令牌 API Key**：个别站点用 API Key 访问控制（已知：馒头）。
- **站点 User-Agent**：取 Cookie 时的 UA，配合可跳过 Cloudflare 人机验证，建议填。
- **站点流控**：单位周期访问次数/间隔，控制访问频率防压垮站点。
- **代理**：走已配置代理（需 `PROXY_HOST`）。
- **浏览器仿真**：适用于人机验证严格的站点，会变慢、更耗资源，需下载浏览器内核。

## CookieCloud 批量同步（推荐）
1. 浏览器装 CookieCloud 插件，登录站点后同步 Cookie 到 CookieCloud 服务端。
2. MoviePilot 设定 -> 站点 维护参数并开启 CookieCloud 同步（地址与插件一致，可用本地或远端服务）。
3. 设定 -> 服务 运行一次「同步CookieCloud站点」：自动添加站点、生成 RSS 链接和图标。

## 站点「更新」按钮（自动获取 Cookie）
输入站点 用户名/密码，系统模拟登录抓 Cookie（需浏览器内核 + 配置 OCR 服务器）。因验证码/人机验证不保证 100% 成功，失败仍需手工登录取 Cookie。

## 支持站点举例
- 私有站点（大量）：憨憨、观众、馒头、天空、春天、家园、彩虹岛、CARPT、AGSVPT、NovaHD、PlayLet、天雪、UBits、咖啡、下水道、自由农场 等。
- 公开站点：Nyaa、TorrentGalaxy、ACG.RIP、MiKan、动漫花园。

## V3 站点资源/索引
- 资源目录 `resources.v3`，站点索引包 `user.sites.v3.bin`，索引版本 3.0.0。
- V3 不回退 V2 资源；站点分类无法识别时，先确认加载了 V3 资源，再检查 Cookie 和站点页面变化。
- V3 支持影视综合站中的音乐分支，音乐搜索用站点索引的 `music` 分类。

## 优先级作用（不同版本）
- V1：设定 -> 站点 -> 下载优先规则 = 站点优先 时，影响搜索排序与下载。
- V2：设定 -> 规划 -> 下载规则 选「站点优先级」影响选资源策略。
- V3：站点优先级继续参与资源选择，音乐站点分类参与媒体类型过滤。
