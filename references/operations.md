# MoviePilot 操作流程

## 搜索
- 入口：Web 点搜索图标或 `Ctrl+K` / `command+k`，弹出聚合搜索窗口；可搜媒体信息、人物、站点资源、音乐。
- 设定 -> 搜索：
  - **媒体数据源**：搜索展示的媒体信息源及顺序。
  - **搜索站点**：搜索时使用的站点范围，站点越多越慢。
  - **过滤规则**：全局过滤资源类型。例：无杜比设备时设默认过滤规则排除 `Dolby[\s.]+Vision|DOVI|[\s.]+DV[\s.]+|杜比视界`。
- 精确匹配：从媒体详情点搜索，带识别转换，若媒体信息源与识别源不一致可能因 TMDB/豆瓣/Bangumi 数据不一致导致搜不到。
- 模糊搜索：在聚合搜索选「站点资源」，直接返回站点搜索结果，不过滤、不优化。
- V3 资源搜索页流式实时展示进度与预览；反向代理建议开启 http2 并预留长超时。
- AI 推荐：配置智能助手下 `AI_RECOMMEND_ENABLED` 后，资源搜索结果页有 AI智能推荐，基于当前结果做进一步筛选排序。

## 订阅（自动检索/追更）
- 入口：媒体卡片或媒体详情点「订阅」按钮。音乐订阅从音乐搜索/详情创建。
- 添加后约 3 分钟内做一次全订阅站点搜索补存量；未下载完进入「订阅刷新」。
- **订阅刷新**：后台定期检查各站点新增资源 -> 识别匹配 -> 符合则添加下载；每次只处理增量。
- 订阅模式（设定 -> 订阅）：
  - **自动**：内置爬虫，随机间隔取各订阅站点种子列表页。间隔约 20-40 分钟，全天约 32 次访问，早 7:00 开始，32 次后停止。支持促销标识、做种数（可用于优先级/过滤规则）。
  - **站点RSS**：用站点 RSS 链接，间隔可自由设置（须 >5 分钟）。不支持促销检测与做种数判定。
- **订阅搜索**（可开）：因列表/RSS 条数限制会漏资源，每 24 小时可对订阅做一次搜索补漏；时间间隔不可调，若无漏订问题建议不开（减少站点压力）。
- **洗版**（画质升级）：匹配到资源并成功下载后订阅不自动删除；会继续下载更高优先级资源，直到洗版优先级最高。仅完结剧集支持洗版。需配合 设定 -> 目录 -> 整理模式 的覆盖模式（总是覆盖 / 仅保留最新版本），或改重命名规则加入区分质量要素。
- 订阅站点范围：全局在 设定 -> 订阅 -> 订阅站点；单个订阅可在「编辑订阅」设定。
- 远程订阅：配好通知渠道后发 `订阅 + 片名` 添加订阅。

## 下载
- 设定中添加下载目录；Docker 需把下载目录根目录映射到容器，且与下载器使用的目录一致。
- 手动下载需先识别资源；下载目录系统自动判定，不能在手动下载时指定。
- 远程下载：配好 微信/Telegram/Slack/SynologyChat/VoceChat 后，发片名即可搜索下载。V1 用 `AUTO_DOWNLOAD_USER` 控制择优下载 vs 发列表选；V2 在界面调整。
- 音乐下载复用现有下载器/任务流程，不建内置音乐库；需在 设定 -> 目录 配音乐目标目录（与下载器目录映射一致），整理后由外部媒体服务器扫描。

## 文件整理
- V2 支持按目录用「下载器监控整理」或「目录监控整理」。
  - 下载器监控：自动整理间隔 5 分钟；启用的下载器且设了对应目录都会自动整理。
  - 目录监控：实时。避免对网盘目录用目录监控（易触发大量 API 被流控）。
- V1：监测下载器任务状态自动整理，间隔 5 分钟；多个下载器默认只监控第 1 个；设了种子标签则只整理带标签的任务。
- 非 MoviePilot 添加的任务，可用「目录监控」插件；需按系统章节调整文件系统参数，并打开下载器「为不完整文件添加扩展名」避免下载中就被转移。
- 音乐整理：读音频标签+技术参数，按 `艺术家/专辑 (年份)/曲序 - 歌曲.扩展名` 命名。音乐重命名格式可用 Jinja2 字段：artist、album_artist、album、title、track、disc、year、fileExt。整理会迁移同目录同主干的 .lrc/.txt/.lyricsfile.yaml。刮削会写标签封面（硬链接模式也反映到底层文件）。

## 插件
- V1.0+ 200+ 插件，V2.0+ 400+ 插件。
- 通过 `PLUGIN_MARKET` 加第三方仓库地址（仅支持 Github main 分支，多个用 `,` 分隔）；V2 在插件页管理图标维护。下载/更新需能连 Github 并配置 Github Token。
- 官方插件库：https://github.com/jxxghp/MoviePilot-Plugins
- 插件需声明支持 V2 否则 V2 市场不显示。开发见 MoviePilot 插件开发指南（V3）。

## 通知 / 智能助手
- 系统状态/错误通过系统通知提醒，Web 右上角消息中心查看。
- V2.0+ API_TOKEN ≥16 位；同类型多配置时回调地址加 `&source=配置名称`（英文，特殊字符需 URL 编码）。
- 通知可按用户隔离：用户在个人信息维护对应渠道 ID；交互类消息只有操作人收到；用户操作类通知按范围发给操作人/管理员/全体；系统广播类按范围发给管理员/全体。
- 智能助手启用后可承担远程交互：发文本分析搜索/下载/整理/订阅问题、发图片识别、发文件保留原始附件并交本地路径给助手、发语音先识别再对话。
- 图片/音频/语音开关：`LLM_SUPPORT_IMAGE_INPUT`（默认 true）、`LLM_SUPPORT_AUDIO_INPUT`（默认 false）、`LLM_SUPPORT_AUDIO_OUTPUT`（默认 false）。

## 诊断（doctor，离线自教）
- `moviepilot doctor`：不调后端 API，直接检查本地配置/运行时/进程/端口/日志/依赖/数据库/前端资源/Docker。
- 适用：WebUI、后端 API、Agent、插件全不可用时，或提交 Issue 前收集诊断。
- 用法：
  - `moviepilot doctor` / `--json` / `--fix` / `--deep`
  - 容器内：`docker exec -it <container> moviepilot doctor [--json|--fix]`
  - compose：`docker compose exec <service> moviepilot doctor`
  - 容器已退出：`docker run --rm --entrypoint python -v <config-dir>:/config <image> -m app.cli doctor`
  - 安全模式：`moviepilot start --safe`
- `--json` 结构化输出；`--fix` 白名单安全修复；`--deep` 更深入（可能更慢，含 PostgreSQL TCP 连通性）。
- 默认只读检查项：运行路径、关键配置（API_TOKEN/PORT/NGINX_PORT/代理/安全模式）、进程与端口、日志线索、核心依赖（FastAPI/Pydantic/SQLAlchemy/Uvicorn/CloakBrowser）、SQLite 完整性、前端资源存在性、Docker 可用性。
